# AI Resume & Interview Assistant

## Project Overview

AI Resume & Interview Assistant is a web-based application designed to help students and job seekers improve their resumes and prepare for interviews. The application provides resume upload functionality, ATS (Applicant Tracking System) score analysis, interview practice questions, and AI-based resume improvement suggestions through a simple and user-friendly interface.

This project was developed as a Major Project using React, Node.js, Express, and MongoDB.

---

# Problem Statement

Many job applicants are rejected before reaching the interview stage because their resumes are not optimized for Applicant Tracking Systems (ATS). Additionally, candidates often lack proper interview preparation and personalized guidance.

The objective of this project is to provide a platform where users can upload resumes, analyze ATS compatibility, receive improvement suggestions, and practice interview questions in one place.

# Installation

## Clone Repository

```bash
git clone https://github.com/Vansh2731/AI-Resume-Assistant.git
```

## Frontend

```bash
npm install
npm run dev
```

Runs at

```
http://localhost:5173
```

---

## Backend

Open another terminal

```bash
cd backend
npm install
node server.js
```

Runs at

```
http://localhost:5000
```
